# Smart Public Service Jakarta - Resilience Dashboard v7.0

Dashboard Intelijen Ketahanan Perkotaan Lengkap dengan **Udara Jakarta Ranking & Recommendation Widgets (udara.jakarta.go.id)**, **BPBD Waterlevel API**, **Pantau Banjir Spatial Map**, dan **Dynamic Reactive Recharts**.

## 🚀 Fitur Baru v7.0:
- **Kualitas Udara Terbaik & Terburuk Widget (`AirRanking.tsx`):** Menampilkan daftar kecamatan/stasiun dengan nilai ISPU terbersih dan tertinggi khas udara.jakarta.go.id.
- **Kartu Rekomendasi Aktivitas (`AirRecommendationCards.tsx`):** Rekomendasi aktivitas outdoor bagi warga & kelompok sensitif.
- **Peta Pemantau Kualitas Udara (`JakartaMap.tsx`):** Marker terpadu stasiun SPKU DLH Jakarta dan layer titik genangan Pantau Banjir.
